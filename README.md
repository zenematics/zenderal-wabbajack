# Zenderal

An **Enderal: Forgotten Stories Special Edition** modlist for [Wabbajack](https://www.wabbajack.org), built on three things: **bug fixes**, **modern combat** and **modern visuals**.

> **Public alpha.** Expect rough edges and report what you find.

## Requirements

- **Enderal: Forgotten Stories (Special Edition)** on Steam
- A **Nexus Mods** account (Premium makes downloads automatic)
- About **110 GB** of downloads and **160 GB** for the installed list, so roughly **270 GB** free in total
- A PC that can run an ENB at your resolution

## Installation

1. Install [Wabbajack](https://www.wabbajack.org).
2. Run Enderal SE once from Steam, so its game files exist.
3. In Wabbajack, open **Browse lists**, enable **Show unofficial lists**, and pick **Zenderal**.
4. Choose an install folder and a downloads folder **outside** Program Files and outside the Enderal game folder.
5. When it finishes, launch `ModOrganizer.exe` from the install folder and start the game through SKSE.

## Optional mods

Ultrawide players: in MO2, enable the Vel'dun patch for your aspect ratio (21:9 or 32:9) and leave the others off.

## Zenderal's own files

The list's custom patches are on Nexus as **Zenderal - Patch Collection**. Their source is at [stefangouldson/zenderal-patches](https://github.com/stefangouldson/zenderal-patches).
